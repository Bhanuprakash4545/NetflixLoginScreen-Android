Netflix Login Page – Android UI

This project is a simple and clean Netflix-style login screen created using **Android Studio XML layouts**.  
It is built as part of the **CSE225 Mobile Application Development** assignment.



Features
- Netflix-inspired UI design  
- Email / phone input field  
- Password field with eye icon  
- Sign In button  
- Remember me checkbox  
- “Need help?” link  
- Facebook login option  
- Built using **ConstraintLayout** for responsive design



Tech Stack
- Android Studio
- XML Layouts
- ConstraintLayout
- Java + Kotlin (optional for backend logic)
